# SCENTOZ — Haute Parfumerie · Maison de Parfum

An ultra-luxurious, modern e-commerce storefront for **SCENTOZ**, an artisanal Haute Parfumerie blending the botanical hydro-distillation heritage of Kannauj with Grasse's modern French olfactory artistry.

---

## 🏛️ Brand Identity & Typography Architecture
- **Brand Name**: **SCENTOZ** (`MAISON DE PARFUM · GRASSE & KANNAUJ`)
- **Heading Font**: **`GEO SANS LIGHT`** (`GeosansLight`, `Geo Sans Light`) — Minimal, geometric, timeless luxury aesthetic applied to all brand logos, headlines, flacon labels, product titles, and section banners.
- **Body Font**: **`AVENIR`** (`Avenir`, `Avenir Next`) — Refined, highly legible modern luxury typography for descriptions, navigation, pricing, olfactory notes, and checkout forms.
- Bundled local `.woff` fonts with CDN fallbacks for instant online and offline rendering.

---

## 🎨 User-Specified Luxury Color Palette
Constructed on a light porcelain/ivory canvas (no black background) using the 5 precise palette tones:
- **`rgb(246, 217, 210)`** / `#F6D9D2` (Powder Blush Champagne)
- **`rgb(236, 189, 198)`** / `#ECBDC6` (Rose Quartz)
- **`rgb(216, 169, 193)`** / `#D8A9C1` (Mauve Orchid)
- **`rgb(184, 152, 193)`** / `#B898C1` (Lilac Amethyst)
- **`rgb(146, 131, 169)`** / `#9283A9` (Smoky Slate Plum)
- *Accent*: `#6B1D45` / `#852256` (Deep Royal Plum) for top announcement strip and interactive accents.

---

## 💎 Commerce Architecture & Indian Market Features
- **Default Currency**: **Indian Rupee (INR - `₹`)** across all products, cart summaries, and checkout flows.
- Multi-currency switcher included for international patrons (`USD $`, `EUR €`, `GBP £`, `AED د.إ`).
- **Comprehensive Indian Checkout System**:
  - Pan-India delivery address form with City, State, and Pincode validation.
  - **UPI Integration** (Instant Google Pay, PhonePe, Paytm, BHIM UPI).
  - **Credit/Debit Cards & NetBanking** (Visa, Mastercard, RuPay, Amex).
  - **Cash on Delivery (COD)** with instant order confirmation.
  - Complimentary Express insured delivery (BlueDart Express Air) + 2 sample vials with every flacon.

## 🚀 Running the Storefront Locally

### Option 1: Direct Browser Access
Open `index.html` in any web browser.

### Option 2: Local HTTP Server (Recommended)
Run using Python in PowerShell:
```powershell
python -m http.server 8000
```
Then visit:
`http://localhost:8000`
